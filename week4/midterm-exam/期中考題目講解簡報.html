第一題（a）到（e）

(a) char 通常占 1 byte。
TC++ 以 sizeof(char) == 1 定義一個 byte。byte 不一定固定為 8 bits，但 char 一定占 1 byte。
(b) 7 / 2 * 2.0 的結果為 7.0。
F7 / 2 先做整數除法得到 3，再算 3 * 2.0，結果是 6.0。
(c) b != 0 && a / b > 1 在 b = 0 時不會除以零。
T&& 會短路求值。左邊為 false 後，右邊不執行。
(d) 任何 for 都能改寫成效果相同的 while。
T初始化放在迴圈前，條件留在 while，更新放在每輪末端。若有 continue，也要讓更新步驟照原本時機執行。
(e) 區域變數與全域變數同名時，該 scope 內直接使用名稱會存取區域變數。
T區域變數會遮蔽同名的全域變數。

第一題（f）到（j）

(f) binary search 可以用在未排序的一維陣列。
F每次排除一半的前提是資料已有順序。未排序時無法判斷目標在哪一半。
(g) call by value 的參數在函數內被修改，不影響呼叫端原變數。
T函數收到的是一份複本，改的是複本。
(h) 函數可有多個 return，但一次呼叫最多執行一個。
T執行 return 後，該次函數呼叫立刻結束。
(i) char str[5] = "hello"; 沒有出錯的機會。
F"hello" 還需要結尾的 '\0'，共 6 格；陣列只有 5 格。
(j) 每次以同一 seed 呼叫一次 srand，後續 rand 數列相同。
T偽隨機數產生器從相同起點開始，會走出相同序列。

第三題（a）：陣列傳入函數後只剩位址資訊

void f(int a[]) {
    cout << sizeof(a);
}

int data[10];
f(data);
  • 1
    輸入：呼叫端有一個 10 格的 int 陣列。
  • 2
    傳入時：int a[] 在函數參數中視為 int* a。函數收到第一個元素的位址，沒有收到「10 格」這項資訊。
  • 3
    結果：sizeof(a) 得到指標本身的大小，不是原陣列大小。

第三題（b）：遞迴的代價與適用場景

一個壞處

每次呼叫都要保留當次函數的區域資料與返回位置。呼叫太深會占用大量 call stack，甚至發生 stack overflow。

一個適合場景

資料本身具有遞迴結構，例如樹；或問題能自然拆成同型態的更小問題，例如河內塔。

本題只要求各寫一個。答案不必列滿所有缺點，也不必解釋演算法細節。
不要混淆：「程式碼比較短」不代表一定比較快；遞迴若重複計算，同一個子問題可能被算很多次。

第三題（c）（d）：先列遞迴數列，再改成迴圈

int weird(int n) {
    if (n == 0) return 2;
    if (n == 1) return 1;
    return 3 * weird(n - 1)
             - weird(n - 2);
}
w₀=2, w₁=1, w₂=1, w₃=2, w₄=5, w₅=13
int weirdRep(int n) {
    if (n == 0) return 2;
    if (n == 1) return 1;
    int prev2 = 2, prev1 = 1;
    int current;
    for (int i = 2; i <= n; i++) {
        current = 3 * prev1 - prev2;
        prev2 = prev1;
        prev1 = current;
    }
    return current;
}
三個變數的角色：prev2 存 wᵢ₋₂，prev1 存 wᵢ₋₁，current 算新的 wᵢ。

第三題（e）：排序一次，查詢 k 次

方法一：k 次 linear search = O(kn)
方法二：排序 O(n log n) + k 次 binary search O(k log n)
總計：O(n log n + k log n)
1

比較兩者

n log n + k log n < kn

2

整理

n log n < k(n − log n)

3

n 夠大時

n − log n 約等於 n

4

粗略門檻

k > log n

小例子：若 n = 1024，log₂n = 10。查詢數遠多於約 10 次時，先排序通常開始有優勢。實際時間仍會受常數與實作影響。

第三題（f）：ptr2 仍指向已釋放的記憶體

int* ptr = new int[10];
int* ptr2 = ptr;
delete[] ptr;
ptr2[3] = 7;
  • 1
    ptr 與 ptr2 一開始保存同一塊記憶體的位址。
  • 2
    delete[] ptr 釋放那塊記憶體。它不會自動把 ptr2 改成 nullptr。
  • 3

第三題（g）：用 INT_MAX 表達「int 的最大值」

可攜性

不同平台的 int 範圍可能不同。INT_MAX 由目前環境提供正確值。

可讀性

INT_MAX 直接說明用途；2147483647 只是一串數字。

維護性

程式不需要把某一種平台的數值寫死在原始碼裡。

本題至少答出一個合理原因即可。最直接的答案是跨平台正確性與可攜性。

第四題（a）：頻率陣列解法

Function CountCopies(s, t):
    freqS[0..25] = {0}
    freqT[0..25] = {0}

    for each ch in s:
        freqS[ch - 'a'] += 1

    for each ch in t:
        freqT[ch - 'a'] += 1

    answer = infinity
    for i from 0 to 25:
        if freqT[i] > 0:
            answer = min(answer,
                         floor(freqS[i] / freqT[i]))

    return answer
  • 1
    掃過 s：O(n)。
  • 2
    掃過 t：O(m)。
  • 3
    檢查 26 個字母：O(26)。
總時間：O(n + m + 26) = O(n + m)。
額外空間：兩個固定 26 格陣列，所以是 O(1)。

第四題（b）：距離恰好為二是什麼

把節點想成同學，把一條邊想成「兩人直接認識」。

v

從指定節點出發

題目要找與 v 距離恰好為二的節點。

i

走第一步

先走到 v 直接相鄰的節點 i。

j

再走第二步

從 i 再走一條邊，到候選節點 j。

最重要的一句話：j 必須「走兩步可以到」，而且「走一步到不了」。
所以還要排除兩種情況：j 是 v 本身；或 j 原本就和 v 直接相鄰。
先不要講矩陣。請同學口頭說明「朋友的朋友，但不是自己，也不是已經直接認識的人」。確認概念後再進入下一頁。

小例子：從節點 1 出發

A12345
101101
210010
310011
401100
510100

A[x][y] = 1 表示 x 與 y 直接相連。

  • 1
    先看第 1 列：值為 1 的位置是 2、3、5。所以節點 1 的直接鄰居是 2、3、5；它們的距離是 1，不是答案。
  • 2
    以 2、3、5 當中繼點，再各走一步。經過 2 可到 1、4；經過 3 可到 1、4、5；經過 5 可到 1、3。
  • 3
    排除自己與直接鄰居。1 是自己；2、3、5 是直接鄰居；只剩節點 4。
答案是 1 個：只有節點 4 與節點 1 的距離恰好為二。

逐個檢查：為什麼最後只算節點 4

第一步到 i第二步到 j決定原因
i = 2j = 1不算回到 v 本身
i = 2j = 4標記 44 不是自己，也沒有和 1 直接相連
i = 3j = 1不算回到 v 本身
i = 3j = 4不重複加found[4] 已經是 true
i = 3j = 5不算1 與 5 直接相連，距離是 1
i = 5j = 1、3不算1 是自己；3 是直接鄰居
found 的用途：節點 4 可以經過 2 或 3 抵達，但答案只能算 1 次，所以只記錄「是否找到」，最後再統計 true 的數量。

虛擬碼：把「走兩步」寫成兩層迴圈

Function CountDistanceTwo(A, v, n):
    // target 代表 v 的索引，因為 C++ 的索引從 0 開始，所以要減一
    target = v - 1
    found[0..n-1] = {false}

    for middle from 0 to n-1:
        if A[target][middle] == 1:
            for candidate from 0 to n-1:
                if A[middle][candidate] == 1
                   and candidate != target
                   and A[target][candidate] == 0:
                    found[candidate] = true

    count = 0
    for candidate from 0 to n-1:
        if found[candidate]: count += 1
    return count
  • 1
    middle 是第一步到達的中繼節點。
  • 2
    candidate 是第二步到達的候選節點。
  • 3
    candidate != target 排除走回自己。
  • 4
    A[target][candidate] == 0 排除直接鄰居。
時間複雜度：最壞情況檢查 n 個 middle，每個再檢查 n 個 candidate，所以是 O(n²)。最後統計 O(n)，不改變總結果。

第五題（a）：先把文字需求翻成介面

需求設計原因

第五題（a）：完整 struct 實作

int gcd(int a, int b) {
    if (a % b == 0) return b;
    return gcd(b, a % b);
}

struct Fraction {
    int num;
    int den;

    void simplify() {
        int divisor = gcd(num, den);
        num /= divisor;
        den /= divisor;
    }

    int quotient() const {
        return num / den;
    }
};
例：6/8
gcd(6,8) = 2
simplify 後：3/4
quotient 回傳：0
num = 0 也可處理：gcd(0, den) 會得到 den，約分後成為 0/1。
這是參考解答版本。也可以用迴圈寫 gcd；只要行為符合題目即可。

第五題（b）：先相加，再約分，再回傳分子

int numeratorOfSum(const Fraction& a,
                   const Fraction& b) {
    Fraction sum;
    sum.num = a.num * b.den
            + b.num * a.den;
    sum.den = a.den * b.den;
    sum.simplify();
    return sum.num;
}
  • 1
    輸入：兩個 Fraction，以 const reference 傳入。避免複製，也保證函數不改 a、b。
  • 2
    計算：分子為 ad + bc，分母為 bd。
  • 3
    輸出：先 simplify，再回傳約分後的 sum.num。
這裡選全域函數：運算地位對稱，同時使用兩個 Fraction，不特別屬於其中一個物件。寫成成員函數也可，但要清楚說明設計理由。
