private 保護物件內部資料

對外提供必要操作，避免外部把資料改成無效值。

class Score {
private:
  int value;
public:
  Score(int v) : value(v) {}
  int get() const { return value; }
  void set(int v) { if (v >= 0) value = v; }
};
  • 1
    輸入建立 Score 時，v 交給建構子。
  • 2
    過程value 是 private；外部透過 get、set 讀寫。
  • 3
    結果set 擋掉負分，物件保留有效資料。

static 與 friend

static 資料由所有同類物件共用；friend 讓指定函式存取 private。

class Counter {
  static int alive;
public:
  Counter() { ++alive; }
  ~Counter() { --alive; }
  static int count() { return alive; }
};
int Counter::alive = 0;
  • 1
    static alive所有 Counter 物件共用一個計數器。
  • 2
    建立／銷毀建構加一，解構減一。
  • 3
    friend只有需要讀取 private 資料時才指定友元。

== 是一個函式呼叫

a == b 可呼叫 a.operator==(b)；是否相等由函式內容決定。

class Point {
  int x, y;
public:
  bool operator==(const Point& rhs) const {
    return x == rhs.x && y == rhs.y;
  }
};
  • 1
    左邊a 是呼叫函式的物件，也就是 this。
  • 2
    右邊b 進入 rhs 參數。
  • 3
    const比較不會修改左側 a。

[] 的兩個版本

要讓 a[i] = 4 成立，非 const 版本必須回傳原元素的參考。

int operator[](int i) const {

  return data[i];

  • 1
    const 物件只能呼叫第一版，取得 int 值。
  • 2

  • 3
    賦值a[i] = 4 才會寫回 data[i]。

operator= 與自己賦值

a = a 時，來源與目標是同一物件；若先刪資料，後面就讀不到。

Buffer& operator=(const Buffer& rhs) {
  if (this == &rhs) return *this;
  int* fresh = new int[rhs.n];
  for (int i=0; i<rhs.n; ++i)
    fresh[i] = rhs.data[i];
  delete[] data;
  data = fresh; n = rhs.n;
  return *this;
}
  • 1
    檢查this == &rhs 比對兩個物件的位址。
  • 2
    先複製先準備 fresh，再釋放舊陣列。
  • 3
    回傳return *this 讓 a = b = c 可成立。

成員版 + 的左操作數

只有 Vector::operator+(int) 時，v + 2 可用，2 + v 需要非成員函式。

Vector operator+(const Vector& v, int d) {
  Vector out(v);
  for (int i=0; i<out.size(); ++i)
    out[i] += d;
  return out;
}
Vector operator+(int d, const Vector& v) {
  return v + d;
}
  • 1
    v + 2左邊是 Vector，可呼叫成員函式。
  • 2
    2 + v左邊是 int，不能呼叫 Vector 的成員函式。
  • 3
    解法非成員版把 2 + v 轉交給 v + 2。

  • 1
    Tlarger 時，T 換成 int。
  • 2
    條件型別必須支援 <，因為函式會比較 a、b。
  • 3
    結果兩次呼叫分別得到 7 和 2.5。

自編猜題 11｜第 15 講

Template 的型別條件

這個模板能套用在沒有 operator< 的型別嗎？

template<typename T>
T larger(T a, T b) {
  return (a < b) ? b : a;
}
答案：不能直接使用
真正用該型別呼叫時，編譯器需要 a < b；若型別沒有定義 <，會編譯失敗。
