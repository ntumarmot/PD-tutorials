# Week 2：從 struct 走到 class（兩小時授課，三小時素材）

## 本課要讓學生帶走什麼

學生要能自己解釋並寫出：

1. `struct` 把同一筆資料的欄位放在一起，例如一位學生的姓名與分數。
2. 成員函式是寫在 `struct` 或 `class` 裡的函式；`alice.print()` 使用 `alice` 自己的資料。
3. `private` 讓外部不能直接修改欄位；公開的 `setScore()` 可以先檢查分數是否合法。
4. 建構子在物件建立時執行，讓姓名與分數有初始值。

C++ 的 `struct` 和 `class` **都**能放欄位與成員函式。這裡用 `struct` 開始、再用 `class` 練習存取限制。沒有明寫存取權限時，`struct` 成員預設為 `public`，`class` 成員預設為 `private`。

## 課前準備

- 從空白檔打一次 01–06，並自己做完 [學生練習.md](學生練習.md) 的七關，尤其確認 `class` 後面的分號與 `private/public` 的位置。
- [教師逐題答案.md](教師逐題答案.md) 列出每關要寫的關鍵部分；`教師參考_01-03.cpp`、`教師參考_04-06.cpp`、`06_bank_account.cpp` 是可編譯的整合答案。上課不要先把答案投出來。
- 預先在學生的電腦上確認 C++ 編譯器、中文字輸出與執行方式。例如在 `教材/week2` 目錄：`clang++ -std=c++17 03_class_student.cpp -o class_demo && ./class_demo`。
- 先問學生會不會宣告變數、呼叫函式、寫 `if`。若不熟，將第一段放慢。

## 現場打程式的節奏

每次只加約 5–10 行：**先問預測 → 打字 → 編譯執行 → 對照預測 → 請學生改一個值再跑**。程式碼字型放大。出現編譯錯誤時，先讓學生指出是哪一行和哪個符號，再給提示。

01 的重點是 `printStudent(bobName, aliceScore)`：參數型別正確，所以能編譯，卻把名字與分數配錯。02 把兩個欄位放進同一個 `Student`。03 讓外部透過 `setScore()` 更新私有分數，因此輸入 120 後，原本的 80 保持不變。這三段連成一個問題逐步改善的故事。

如果學生在第 3 關還不能自己寫出陣列與迴圈，就先把這關做完，再進到 `class`。兩小時是授課時間，三小時是備課量；是否往下講，依學生能否自己預測、寫出並修改程式決定。

## 對照老師講義

- 第 10 章《Self-defined Data Types (in C)》第 4–12 頁：`struct`、欄位，以及把整筆資料傳給函式；第 26–32 頁：成員函式。
- 第 11 章《Classes》第 8–11 頁：`class`、`public/private` 與資料隱藏；第 18–23 頁：建構子與解構子。
- `typedef`、亂數、`friend`、`static`、物件指標、複製建構子先留到後續課程。這裡的解構子範例只展示時機，沒有教動態記憶體的完整資源管理。

本安排根據現有 Week 1 與老師講義製作；學生的實際程度尚未確認，上課時按他的回答調整。
