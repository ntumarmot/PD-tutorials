# Week 2 七關答案對照（老師用）

這份對照 [學生練習.md](學生練習.md)。程式檔是各階段完成後的**整合版本**：第 1–3 關見 [教師參考_01-03.cpp](教師參考_01-03.cpp)，第 4–6 關見 [教師參考_04-06.cpp](教師參考_04-06.cpp)，第 7 關見 [06_bank_account.cpp](06_bank_account.cpp)。前面的函式在後面的關卡可能被改寫，所以以下另外列出每關當下需要的寫法。

## 第 1 關：整筆資料傳給函式

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Student {
    string name;
    int score;
};

void printStudent(Student s) {
    cout << s.name << ": " << s.score << '\n';
}

int main() {
    Student alice = {"小明", 80};
    Student bob = {"小華", 95};
    printStudent(alice);
    printStudent(bob);
}
```

預期印出小明 80、小華 95。重點是函式接收一個 `Student`，呼叫端不再各傳一次姓名和分數。這個全域函式在第 3 關會搬進 `struct`，所以不會留在整合答案裡。

## 第 2 關：回傳分數較高的 Student

```cpp
Student better(Student a, Student b) {
    if (a.score >= b.score) {
        return a;
    }
    return b;
}
```

`>=` 讓同分時回傳第一位。測 80 對 95 應回傳 95 分者；95 對 80 回傳 95 分者；同為 80 時回傳第一位的姓名。只回傳 `int` 分數會遺失勝出者的姓名。

## 第 3 關：成員函式與及格人數

```cpp
struct Student {
    string name;
    int score;

    void print() {
        cout << name << ": " << score << '\n';
    }

    bool isPass() {
        return score >= 60;
    }
};

Student students[3] = {{"小明", 59}, {"小華", 60}, {"小安", 100}};
int passCount = 0;
for (int i = 0; i < 3; i++) {
    if (students[i].isPass()) {
        students[i].print();
        passCount++;
    }
}
cout << "及格人數：" << passCount << '\n';
```

上面陣列與迴圈要放在 `main` 裡。應印出小華、小安與及格人數 2。59 不及格，60 剛好及格。

## 第 4 關：私有欄位的讀取

在 `class Student` 的 `public:` 區域加入：

```cpp
string getName() {
    return name;
}

int getScore() {
    return score;
}
```

類別外的比較函式改成：

```cpp
Student better(Student a, Student b) {
    if (a.getScore() >= b.getScore()) {
        return a;
    }
    return b;
}
```

`getScore()` 讓外面讀取分數，但沒有開放 `alice.score = 120`。學生若把 `score` 改成 `public` 才讓程式編譯，就沒有完成這關的目的。

## 第 5 關：更新分數並回報結果

```cpp
bool setScore(int newScore) {
    if (newScore < 0 || newScore > 100) {
        return false;
    }
    score = newScore;
    return true;
}
```

初始 80 分，依序輸入 `-1, 0, 100, 101`，成功與目前分數應為 `(false,80)`、`(true,0)`、`(true,100)`、`(false,100)`。`score = newScore` 必須放在檢查之後。

## 第 6 關：兩個建構子

```cpp
Student() {
    name = "未命名";
    score = 0;
}

Student(string studentName, int initialScore) {
    name = studentName;
    score = 0;
    setScore(initialScore);
}
```

要先將 `score` 設為 0，再呼叫第 5 關的 `setScore`。因此給 120 分時，檢查失敗，分數仍是 0。建立 `unknown`、`alice`、`bob` 後，應印出「未命名: 0」、「小明: 80」、「小華: 0」。

## 第 7 關：銀行帳戶

完整可編譯答案見 [06_bank_account.cpp](06_bank_account.cpp)。核心判斷是：

```cpp
bool deposit(int amount) {
    if (amount <= 0) return false;
    balance += amount;
    return true;
}

bool withdraw(int amount) {
    if (amount <= 0 || amount > balance) return false;
    balance -= amount;
    return true;
}
```

存 100 成功，存 -20 失敗；提 30 成功後餘額為 70，提 200 與提 0 都失敗且餘額仍是 70。加分題 `transferTo` 的一種寫法也在完整程式內：先確認金額合法且餘額足夠，再同時更新兩個帳戶。該參考寫法把轉給自己視為成功、餘額不變；若想改成失敗，題目要先和學生約定規則。

## 看答案前先檢查

請學生先自己編譯並跑題目中的邊界值；卡住時只提示下一個需要的條件或欄位。對照答案時，請他指出「哪個值在什麼條件下改變」，比只核對程式長得一不一樣更能確認理解。
