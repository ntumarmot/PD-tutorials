# Week 2 七關答案（老師用）

完整可編譯程式是 [Vec2_完整答案.cpp](Vec2_完整答案.cpp)。下面按 [學生練習.md](學生練習.md) 的順序列出每關新增的部分，以及要確認的結果。片段需放進同一個 `class Vec2`，第 7 關的第二個函式則放在類別外。

## 第 1 關：class、建構子與讀取

```cpp
class Vec2 {
private:
    int x;
    int y;

public:
    Vec2(int startX, int startY) : x(startX), y(startY) {}

    int getX() const { return x; }
    int getY() const { return y; }

    void print() const {
        cout << '(' << x << ", " << y << ')';
    }
};
```

`const Vec2 fixed(3,4)` 可呼叫 `getX()`、`getY()`、`print()`，因為這些方法保證不改動物件。要單獨觀察 `private` 的錯誤，用一般的 `Vec2 v(3,4); v.x = 8;`，不要用 `fixed.x` 混入 `const` 的限制。

## 第 2 關：會改與不會改的方法

```cpp
void move(int dx, int dy) {
    x += dx;
    y += dy;
}

int lengthSquared() const {
    return x * x + y * y;
}
```

`(3,4)` 經 `move(-1,2)` 後為 `(2,6)`；長度平方是 `2*2 + 6*6 = 40`。`move()` 會改資料，因此不能由 `const Vec2` 呼叫。

## 第 3 關：== 與 !=

```cpp
bool operator==(const Vec2& other) const {
    return x == other.x && y == other.y;
}

bool operator!=(const Vec2& other) const {
    return !(*this == other);
}
```

`*this` 表示呼叫方法的左邊物件；`other` 是右邊物件。`const Vec2&` 讓函式用右邊原本的物件且不修改它；最後的 `const` 保證不修改左邊。只比較 x 或只比較 y 都不足以判定兩個向量相等。

## 第 4 關：+=

```cpp
Vec2& operator+=(const Vec2& other) {
    x += other.x;
    y += other.y;
    return *this;
}
```

從 `(1,2)` 加 `(3,4)` 得 `(4,6)`，右邊仍是 `(3,4)`。回傳 `Vec2&` 是回傳左邊已存在的物件，讓 `(a += b) += c` 可以接著操作。`a += a` 時會得到 `(2*x,2*y)`。

## 第 5 關：+

```cpp
Vec2 operator+(const Vec2& other) const {
    Vec2 result(*this);
    result += other;
    return result;
}
```

從 `(1,2)` 加 `(3,4)` 得到新的 `(4,6)`；原本兩個向量不變。`result` 是函式內的區域物件，函式結束後它的生命週期會結束，所以這裡應**回傳值**，不能回傳 `Vec2&` 指向它。

老師講義的範例把回傳型別寫成 `const MyVector`（仍是回傳值）。此處採 `Vec2` 回傳值；本題需要的是產生新物件、不回傳對區域物件的參考。

## 第 6 關：[] 的兩種版本

```cpp
int operator[](int index) const {
    if (index == 0) return x;
    if (index == 1) return y;
    cerr << "index 只能是 0 或 1\n";
    exit(1);
}

int& operator[](int index) {
    if (index == 0) return x;
    if (index == 1) return y;
    cerr << "index 只能是 0 或 1\n";
    exit(1);
}
```

完整檔案有 `#include <cstdlib>`，供 `exit(1)` 使用。一般物件會優先用非 `const` 版本；它回傳原欄位的參考，所以 `v[0] = 9` 會改到 x。`const Vec2` 用 `const` 版本，得到的是值，不能在左邊指定新值。錯誤索引須另跑一次，程式會立即結束並回傳非零狀態。

## 第 7 關：向量和整數相加

類別內先寫：

```cpp
Vec2 operator+(int scalar) const {
    return Vec2(x + scalar, y + scalar);
}
```

類別外再寫：

```cpp
Vec2 operator+(int scalar, const Vec2& vector) {
    return vector + scalar;
}
```

`v + 3` 的左邊是 `Vec2`，可呼叫它的成員函式；`3 + v` 的左邊是整數，不能呼叫 `Vec2` 的成員函式，所以需要類別外的運算子。類別外函式透過公開的 `vector + scalar` 完成，不需開放私有欄位。`v=(2,5)` 時兩種加法都得 `(5,8)`，v 保持 `(2,5)`。

## 快速核對的順序

先看行為，再看語法：`+=` 有改左邊嗎？`+` 沒改原物件嗎？`==` 有同時比兩個座標嗎？`[]` 能讓一般物件寫入、`const` 物件只讀嗎？最後再看回傳型別、參數的 `const&` 與方法後面的 `const`。若結果不同，讓學生自己加印出找出第一個錯誤狀態。
