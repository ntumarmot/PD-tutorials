# Week 2：class 與 operator overloading

預設 **兩小時授課**，準備約 **三小時素材**。學生已學過 self-defined data type，所以用約 5 分鐘回想 `struct` 的資料欄位即可；本次主力是 `class`、`private/public`、建構子、`const` 成員函式，以及自訂運算子的行為。

## 這堂課用兩個問題串起來

1. `class`：銀行帳戶不能讓外面隨意把餘額改成負數。用 `private` 保護欄位，透過公開函式檢查輸入。
2. operator overloading：自己寫的 `Vec2` 要如何讓 `a == b`、`a += b`、`a + b`、`a[0]` 有清楚且一致的意思？運算子多載是定義這些運算在自訂類別上的行為。

老師現場只示範 [01_class_demo.cpp](01_class_demo.cpp) 與 [02_operator_demo.cpp](02_operator_demo.cpp) 的核心幾行。之後學生在自己的空白檔逐關寫 `Vec2`。完整題目在 [學生練習.md](學生練習.md)；[Vec2_完整答案.cpp](Vec2_完整答案.cpp) 和 [教師逐題答案.md](教師逐題答案.md) 是老師備課與核對用。

投影或發給學生時可開啟 [class與運算子多載_教學講義.pdf](class與運算子多載_教學講義.pdf)。它的 LaTeX 原始檔是 [class與運算子多載_教學講義.tex](class與運算子多載_教學講義.tex)；七節末尾各有「接下來可以練習第x關」，可直接切回對應題目。舊版投影片保存在 `舊版_投影片/`。

## 兩小時時程

| 時間 | 老師做什麼 | 學生實際寫什麼 |
| --- | --- | --- |
| 0–12 分 | 從 `struct` 帶到 class，現場打銀行帳戶的私有餘額、建構子、`deposit()`；問 `deposit(-20)` 結果。 | 預測輸出並指出哪個欄位不能由外部改。 |
| 12–27 分 | 說明 `const` 方法代表這個方法不修改物件。 | **關 1**：從空白檔完成 `Vec2` 類別、建構子、讀取與印出。 |
| 27–37 分 | 用 `(3,4)` 計算長度平方的例子提示。 | **關 2**：`move()` 與 `lengthSquared()`，辨別會改與不會改。 |
| 37–45 分 | 用 `02_operator_demo.cpp` 示範 `a == b` 會呼叫 `a.operator==(b)`。 | 預測示範程式三次比較的輸出。 |
| 45–57 分 | 只提醒兩個座標都要相同。 | **關 3**：自己寫 `==` 和重用它的 `!=`。 |
| 57–62 分 | 休息五分鐘，檢查學生能否自己解釋 `const`。 | 休息。 |
| 62–74 分 | 示範 `a += b` 前後的座標，不提供函式本體。 | **關 4**：寫 `+=`，測原值、右邊不變及 `a += a`。 |
| 74–86 分 | 問「新結果放哪裡？原本的 a 能改嗎？」 | **關 5**：寫 `+`，測連續加法和原物件不變。 |
| 86–104 分 | 說明「回傳值」與「回傳參考」的差別；索引只能 0 或 1。 | **關 6**：寫可讀、可改的兩個 `[]`。 |
| 104–118 分 | 問為什麼 `3 + v` 不能讓整數呼叫 `Vec2` 成員函式。 | **關 7**：寫 `v+3` 和 `3+v`。 |
| 118–120 分 | 請學生說出 `+`、`+=`、`[]` 哪些會修改原物件。 | 不看程式口頭作答。 |

七關約 93 分鐘是學生親手打、編譯、改錯的時間。這個安排適合你講得快、學生也能跟上的情況；若學生在第 3 關還不能自行寫出比較條件，就保留第 7 關到下次，讓他完整做好第 4–6 關。不要把運算子當語法展示後直接跳過學生動手寫。

## 多準備約一小時的延伸

- 15 分：逐行追蹤 `Vec2 a=b;`、`a=b;`、`a+=b;`，分清建立新物件、指定既有物件、累加既有物件。此 `Vec2` 只有整數欄位，編譯器提供的複製與指定可正常複製其值。
- 30 分：閱讀並試跑 [進階_動態陣列與指定.cpp](進階_動態陣列與指定.cpp)。比較只有指標欄位時的淺層複製與這份程式的深層複製，讓學生補上自我指定檢查 `if (this == &other)`，再測 `a = a`。這一段需要學生已理解指標、`new[]/delete[]` 和複製建構子。
- 15 分：請學生自選邊界案例測七個運算子：同一物件比較、`a+=a`、負整數相加、索引 -1 與 2、`const Vec2` 的讀取。錯誤索引要分開執行，因為範例會結束程式。

第 12 章談到帶動態配置的 `operator=`；**不能把 `Vec2` 的預設指定行為直接套到擁有動態陣列的類別**。這個差別放在延伸段處理，避免學生以為所有類別都不用管複製問題。

第 12 章也示範 `<`。本課不把它排入主線，因為二維向量的「比較大小」要先約定規則（例如先比 x、再比 y，或兩個座標都較小才算）；直接寫運算子而不說明規則，學生容易誤以為只有一種標準答案。

## 課前試跑與講義範圍

在 `教材/week2` 目錄執行 `clang++ -std=c++17 -Wall -Wextra -pedantic Vec2_完整答案.cpp -o /tmp/week2_vec2 && /tmp/week2_vec2`。再從空白檔依七關自己做一次，確認課堂時間。上課先顯示題目與測試條件，答案只用來核對。

- 老師第 11 章《Classes》第 8–13、18–21 頁：`class`、存取權限、資料隱藏、建構子；第 45–52 頁可作複製的先備延伸。
- 第 12 章《Operator Overloading》第 19–32 頁：`==`、`!=`、`[]`；第 34–49 頁：指定、`+=`、`+` 與成員／全域函式。
- 本次主線不教 `friend`、`static`、完整繼承，也不要求學生手寫動態陣列類別。若進度足夠，才進入深層複製延伸。

這份課程依學生已學過自訂資料型別來安排；學生是否已學過複製建構子與 `const` 方法，目前尚未確認，課堂上應先用短例子檢查。
